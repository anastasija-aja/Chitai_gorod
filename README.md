# Final_chitai_gorod
Описание проекта:
Продукт: Интернет-магазин книг  https://www.chitai-gorod.ru/

Описание тестируемой системы:
«Читай-город» — это официальное приложение книжного интернет-магазина. В нём можно найти художественную и учебную литературу, канцтовары, подарки и сувениры, игры и игрушки, товары для художников, для творчества и хобби. Совершать покупки можно с любого устройства.  
Основная функциональность: 
Поиск и покупка книг, канцтоваров, подарков и сувениров, игр и игрушек, товаров для художников, для творчества и хобби.  
Краткое описание задачи — протестировать продукт https://www.chitai-gorod.ru/ на предмет функциональной готовности.
